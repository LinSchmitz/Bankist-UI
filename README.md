# 💻 Bankist UI Showcase

A modern, interactive landing page built with **Vanilla JavaScript, HTML, and CSS**.  
Focuses on advanced **DOM manipulation** and smooth user experience.

## [🔗 Live Demo](https://linschmitz.github.io/Bankist-UI/)

## 🚀 Features

- 📌 Modal window (open/close with overlay & ESC)
- 🔗 Smooth scrolling navigation
- 📑 Tabbed component (Operations section)
- 🌫️ Menu fade animation on hover
- 📌 Sticky navigation (Intersection Observer)
- 👀 Reveal sections on scroll
- 🖼️ Lazy loading images
- 🎞️ Fully functional slider (arrows, dots, keyboard)

## 🧠 Concepts Used

- DOM manipulation & traversal
- Event delegation
- Intersection Observer API
- Lazy loading images
- Component-based JS structure
- Smooth scrolling & UI animations

## ⚙️ How to Run

1. Clone the repo
2. Open `index.html` in your browser

## 📌 Notes

- No frameworks (pure JavaScript)
- Built for learning advanced DOM & UI patterns
- Inspired by modern fintech landing pages
